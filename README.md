# NoHuddle - Sitio en Mantenimiento

🏈 **Versión vanilla HTML/CSS**

## 📁 Estructura del Proyecto

```
NoHuddle-Vanilla/
├── index.html          # Archivo único con todo incluido
├── Images/             # Imágenes necesarias
│   ├── NH-Logo.png     # Logo principal
│   ├── Helmet.png      # Imagen del casco
│   └── football.png    # Imagen del balón
└── README.md           # Este archivo
```

## 🎯 Características

### ✅ **Diseño**
- Responsive design completo
- Animaciones hover
- Efectos de sombra verde

### 🚀 **Optimizado para producción**
- **Un solo archivo HTML** con CSS interno
- **Sin dependencias externas** (excepto Google Fonts)
- **Sin build process** necesario

### 📱 **Responsive Design**
- **Mobile**: Imágenes debajo del texto
- **Tablet**: Transición suave
- **Desktop**: Imágenes posicionadas a los lados
- **Breakpoints**: 768px, 1024px, 1280px

## 🎨 Personalización

### Cambiar colores
```css
/* Buscar y reemplazar en el CSS interno */
background-color: #f3f4f6;  /* Fondo gris claro */
color: #1f2937;             /* Texto principal */
color: #2563eb;             /* Texto "SITIO EN MANTENIMIENTO" */
```

### Cambiar textos
```html
<!-- Editar directamente en el HTML -->
<h1 class="main-title">
    TU TEXTO AQUÍ<br>
    SEGUNDA LÍNEA
</h1>
```

### Cambiar imágenes
1. Reemplaza los archivos en la carpeta `Images/`
2. Mantén los mismos nombres o actualiza las rutas en el HTML

## ✅ Ventajas para tu caso de uso

1. **Fácil implementación**: Un solo archivo para subir
2. **Sin configuración**: No necesitas build tools en el servidor
3. **Funciona offline**: Sin dependencias CDN críticas
4. **WordPress friendly**: Fácil de integrar en cualquier tema/plugin
5. **Rendimiento óptimo**: Carga instantánea
6. **Debugging simple**: Todo el código en un lugar

## 🚀 Para ir en producción

1. **Sube las imágenes** a tu servidor en la carpeta correcta
2. **Copia el index.html** donde necesites
3. **Configura tu servidor web** para mostrar la página
4. **¡Listo!** - No hay más pasos
