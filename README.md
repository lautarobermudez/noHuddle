# NoHuddle - maintenance page

A single-file, responsive **HTML/CSS** maintenance page I built for [nohuddle.com.ar](https://nohuddle.com.ar), a Spanish-language NFL news site I work on.

## Details
- One `index.html` with internal CSS; no build step and no dependencies apart from Google Fonts.
- Responsive layout (breakpoints at 768, 1024 and 1280 px): on mobile the images go below the text, on desktop they sit at the sides.
- Hover animations and a green shadow effect.

## Structure
```
index.html
Images/   # logo, helmet and football images
```

The live site itself runs on WordPress. The content automation I wrote for it is a separate (private) project.
